# Contributing

Thanks for helping improve Vault Toolkit Bridge.

## Before opening an issue

- Search existing issues first.
- Include the Obsidian version, plugin version, operating system, and reproducible steps.
- Do not post vault contents, bearer tokens, or other sensitive data.
- Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

## Development

Node.js 18 or newer is required.

```bash
npm install
npm run check
```

Keep changes focused, use the public Obsidian API where possible, and add or update documentation for user-visible behavior. A pull request should explain what changed, why it is needed, and how it was tested.
